# バッテリ サイクル試験 解析ツール（デモ）

リチウムイオン電池の**充放電サイクル試験データ**を解析し、**劣化評価 → 規格合否 → レポート自動生成**まで行うツールのデモです。
サイクラ（充放電試験機）の大量データから、容量維持率・クーロン効率・内部抵抗などを自動で算出・可視化します。

> 電気設計（電源・バッテリ）の実務知識 × Pythonデータ解析 を組み合わせた成果物です。

---

## 何ができるか

サイクル試験データから自動で：

- **容量維持率（劣化カーブ）**とサイクルあたり劣化率
- **クーロン効率 / エネルギー効率**
- **内部抵抗（DCIR）の推移**
- **放電電圧カーブの推移**（劣化の可視化）
- **規格値との自動合否判定（PASS/FAIL）**
- **グラフ＋サマリの自動レポート（Markdown / PNG / CSV）**

## 実行

```bash
python battery_cycle_analysis.py
```

出力（`out/`）: `report.md` / `capacity_retention.png` / `discharge_curves.png` / `efficiency_dcir.png` / `cycle_metrics.csv`

## 実データへの適用

このデモのデータ生成 `simulate_cycles()` は、誰でも動かせるよう実セルの劣化挙動を模擬しています。
実案件では、ここを**充放電試験機の出力CSV読み込み**に差し替えるだけで、解析・レポート部はそのまま使えます。

```
[現状] simulate_cycles() = セル挙動の物理モデル（データ不要で動作）
[実機] サイクラ出力CSV（電圧/電流/容量/サイクル）を読み込んで同じ解析
```
